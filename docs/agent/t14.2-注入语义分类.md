## 4. 明确不可共存项与回滚边界

**不可共存**：
1. 6 处 HEAD cancellable @Inject（E06/E13/E16/E17/E18/E19）：整方法接管，不可链式共存；回滚边界=方法整体行为。
2. 4 处 @Redirect（E04/E07/E08/E09）：同一 @At 至多一个 @Redirect，与第三方不可共存；迁移后解除。
3. L01 operation 链跳过：与第三方同点 WrapOperation 不共存；链式化阻塞于 descriptor 未闭合。
4. Q-DUP-01/02（L19/L21）：双 JSON 装载；L19 另有 require=1 硬失败面。
5. L06 反射路径：与 AGENTS 反射禁令不可共存。

**回滚边界（迁移实施验证判据）**：
- E04：门控等价（count1+count2 > max(...) 判定与合并落库不变）。
- E07/E09：resolveInventoryClampLimit 调用方保持 2 个（P0 事实 c）；门控与夹取行为不变。
- E08：取源统一语义保持。
- 所有迁移不得改变公共调用面与调用次数；不新增 @Redirect/@Overwrite。
