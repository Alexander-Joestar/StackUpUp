## 2. 初始化顺序

**10.7（运行日志闭合，CLIENT/SERVER 一致）**：
1. LaunchWrapper 载入 tweak：FMLTweaker → MixinTweaker（mixinbooter manifest TweakClass）→ CoremodTweaker；
2. FML 发现 coremod `zone.rong.mixinbooter.MixinBooterPlugin`（manifest FMLCorePlugin）；
3. `[MixinBooter]: Initializing Mixins...` → Mixin 0.8.7 就绪；
4. `[MixinBooter]: Initializing MixinExtras...` → `MixinBooterPlugin.initialize()→initMixinExtras()`：ASM 5.1 不满足 → 注册 `MixinExtrasFixer` transformer；`MixinExtrasBootstrap.init()`；
5. `MixinExtrasService.setup()` 单例创建；
6. `MixinExtrasServiceImpl(version=0.5.0)` 注册 wrapper 注入器（@SugarWrapper/@FactoryRedirectWrapper/@ExpressionInjectorWrapper）；
7. mixin 配置装载（early/late），@WrapOperation 的 Operation 类进入元数据缓存。

**11.13（静态字符串证据，运行 UNKNOWN）**：
- manifest：FMLCorePlugin + **MixinConfigs: mixin.mixinbooter.init.json**，无 TweakClass/FMLCorePluginContainsFMLMod；
- `META-INF/services/IMixinService` → `zone.rong.mixinbooter.service.MixinBooterService`（CleanMix 平台服务，extends AbstractMixinServiceLaunchWrapper）；IMixinServiceBootstrap → MixinServiceBootstrap；
- **MixinExtras 初始化入口变化**：MixinBooterPlugin 常量池无 MixinExtrasBootstrap 引用；`MixinBooterMixinPlugin`（init.json plugin，target 由 @env(DEFAULT) 改为 @env(PREINIT)）含 `MixinExtrasBootstrap` + `Initializing MixinExtras...` + init → 11.13 在 config plugin onLoad 阶段调用；
- 结论：bootstrap 入口仍为 `MixinExtrasBootstrap.init()`，但触发类/阶段不同；**无 11.13 启动日志，运行行为 UNKNOWN**。

## 4. refmap 生成

- 产物：`build/tmp/mixins/mixins.StackUpUp.refmap.json` 与 `build/resources/main/` 同文件 **md5 相同（9b8225cc...）**；含 SRG 映射（CommandGiveMixin.execute → func_184881_a 等）。
- 生成方：Mixin AP（mixinbooter 内嵌 MixinObfuscationProcessorInjection/Targets，经 annotationProcessor(mixin) 挂载）；`build/tmp/mixins/mixins.srg` 为映射输入。
- 运行装载：双端日志 `Remapping refMap mixins.StackUpUp.refmap.json using remapper chain` + `Preparing mixins.stackupup.early.json (21)`（双端 debug 日志实测为 "(21)"；20 注册 vs 21 prepared 为观察项）→ refmap 运行期真实使用。
- MixinExtras AP 对 refmap 无直接参与（只做 handler 校验）；11.13 侧 refmap 生成路径（CleanMix 自带 AP）**无运行证据，UNKNOWN**。

## 5. 处理器签名对比

- 项目使用：7×@WrapOperation + 3×@ModifyExpressionValue + 15×@ModifyReturnValue，handler 全部按契约（返回=被包装类型、尾参 Operation<T>）。
- **0.5.0 ↔ 0.5.5 签名差异**：Operation/MixinExtrasService/ServiceInitializationExtension 逐字节相同；注解差异仅 0.5.2 新增 `order()` 成员（带默认值）——源码/二进制兼容；WrapOperationInjector 0.5.4→0.5.5 仅 lambda 重编号。
- **fork 与上游 0.5.4 的 3 个差异类**：MixinExtrasServiceImpl（CleanMix 兼容补丁：getPackageGeneration/名称翻译/Versioned 处理）、WrapOperationInjector（重构）、MixinExtrasAP（微差）。其余 501 类逐字节相同。
- 结论：**handler 签名面 0.5.0→0.5.4→0.5.5 无破坏性变化（静态闭合）**；0.5.5 注入器实现字节不同，**注入行为在 11.13 运行期未验证（UNKNOWN）**。

## 6. 10.7/11.x 风险与 UNKNOWN 台账

**10.7 基线风险（低）**：R1 AP classpath 双 MixinExtrasAP（Central + mixinbooter 内嵌同 FQCN，字节相同行为等价）；R2 若未来 runtime 额外声明 mixinextras 与内嵌双 provider（禁止引入，T14.7 前）。

**11.x 迁移风险（UNKNOWN）**：
- UNKNOWN-A（新增）：11.13 的 MixinExtras 初始化由 MixinBooterMixinPlugin 触发（字符串证据），无启动日志；停止条件：11.13 启动日志出现 MixinExtrasBootstrap.init()/Initializing MixinExtras 且注入器注册。
- UNKNOWN-B（新增）：fork 补丁（MixinExtrasServiceImpl 服务协商/名称翻译）在 CleanMix 运行期行为未验证。
- UNKNOWN-C（新增）：项目 handler 在 0.5.5 注入器下的实际命中/链式调用未运行验证（签名静态兼容 ≠ 运行注入兼容）。
- 沿用 8.7：①cleanmix 0.7.1 对 minVersion:"0.8" 未实测；③jar manifest/required-after 在 11.13 行为未验证；④`CoremodClassFilter.SKIPPED_PREFIXES`（core/CoremodClassFilter.java:12-20，含 org/spongepowered/、zone/rong/mixinbooter/，**无 com/llamalad7/**）对 11.13 的 559 个 com/llamalad7 类是否进 coremod 链未验证；⑤11.13 无 TweakClass 启动路径未验证；⑥11.13 双 ASM 未验证。

**缺 jar 台账**：本地缓存无 com.cleanroommc:*、无 mixinbooter/11.13（均在线核验，未运行加载矩阵）。

## 7. 审计结论

- 运行时 provider、compileOnly/AP、初始化顺序（10.7）、refmap、handler 签名、fork 差异六项矩阵已闭合（10.7 侧有 jar + 双端运行日志双重证据）。
- 11.x 侧全部运行行为维持 **UNKNOWN**，不宣称兼容；静态已核：0.5.5 同包名无 relocation、内嵌=发布、handler 签名无破坏、初始化入口为 config plugin。
- 本审计不改变 8.6/8.7 停止条件：T14.7 通过前不实施迁移；迁移后停止条件 = 11.13 启动日志（bootstrap 证据 + 全部配置装载 + 无 minVersion 错误 + refmap remap + 注入器注册 + 无 InvalidInjection）。
