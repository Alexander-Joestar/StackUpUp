## 状态口径

- **产物状态**：实现、审计或文档产物有没有形成。

- **剩余风险**：还没闭合的运行、字节码、混淆、第三方源码或安全不变量。

## 待办要点

### 容量与规则基线（P0、T2、T3、T4、T5、T6、T7）

- 产物：源码事实台账、容量目标/写入路径登记、规则快照与 DSL 解析/编译结果。
- 要点：广告容量不得大于真实写入容量；真实写入满足 `storedDelta + remainderCount == offered`；`simulate` 与真实写入分开；规则 reload 只发布完整不可变快照。
- 第三方 jar 无源码时标"无源码不可判定"，不按类名扩容。

### T8 本地化

- T8.0 只有真实客户端 F3+T 前后观察才算收口；静态 `LanguageMap.replaceWith` 只能辅助验证。
- T8.1 的不可变自有译表不等于客户端全局重载桥接；T8.2 仍 `BLOCKED`，缺真实基线时别急着加 listener 或改聊天语义。

### T9/T14 版本与 Mixin

- 当前事实：MixinBooter **11.13**、CleanMix **0.7.1**、入口 **`IMixinConnector`**；10.7、`IEarlyMixinLoader`/`ILateMixinLoader` 等旧 loader 只作历史比较。
- Mixin 优先；只有目标、签名和生命周期证据明确且 Mixin 不足时才用窄范围 ASM。编译通过不能替代运行时和字节码证据。

### T12/T13

- T12 方案 A 已归档；"不吞"只由真实 `remainder` 契约和边界探针验证，禁止恢复写入后重算、回填、重试或补偿。
- T13 要先闭合收缩矩阵，再写窄范围回扩规格；至少覆盖装甲/手持槽、`InvWrapper` 包第三方 `IInventory`、`InventoryLargeChest`，每行关联源码、目标表或机器报告。
- T13 的第三方条目无源码时保持"无源码不可判定"；不得把安全收缩写成功能修复。

### T15/T16
