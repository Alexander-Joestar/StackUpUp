## 状态口径

- **产物状态**：实现、审计或文档产物是否已形成。
- **验收状态**：`PASS`、`PARTIAL`、`BLOCKED`、`UNKNOWN` 或 `FAIL`；未运行、未复核、无源码均不得写成通过。
- **独立复核**：只记录已有的非作者复核证据；本次收口不构成独立复核。
- **剩余风险**：未闭合的运行、字节码、混淆、第三方源码或安全不变量。

## 验收卡

### 容量与规则基线（P0、T2、T3、T4、T5、T6、T7）

- 产物：源码事实台账、容量目标/写入路径登记、规则快照与 DSL 解析/编译结果。
- 验收：广告容量不得大于真实写入容量；真实写入满足 `storedDelta + remainderCount == offered`；`simulate` 与真实写入分开；规则 reload 只发布完整不可变快照。
- 复核/风险：既有产物和测试记录按各文件核对；第三方 jar 无源码时标为“无源码不可判定”，不得按类名扩容。

### T8 本地化

- T8.0 只有真实客户端 F3+T 前后观察可收口；静态 `LanguageMap.replaceWith` 只能辅助验证。
- T8.1 的不可变自有译表不等于客户端全局重载桥接；T8.2 仍 `BLOCKED`，不得在缺少真实基线时新增 listener 或改聊天语义。

### T9/T14 版本与 Mixin

- 当前事实：MixinBooter **11.13**、CleanMix **0.7.1**、入口 **`IMixinConnector`**；10.7、`IEarlyMixinLoader`/`ILateMixinLoader` 等旧 loader 仅作历史比较。
- T14.1–T14.6 仅表示审计产物已形成，验收仍为 `PARTIAL`；T14.7 的准入为 `BLOCKED/PARTIAL`，未通过前不宣称迁移、provider、refmap、混淆或高风险路径闭合。
- Mixin 优先；只有目标、签名和生命周期证据明确且 Mixin 不足时才允许窄范围 ASM。不得以编译通过替代运行时和字节码证据。

### T12/T13

- T12 方案 A 已归档；“不吞”只由真实 `remainder` 契约和边界探针验证，禁止恢复写入后重算、回填、重试或补偿。
- T13 必须先闭合收缩矩阵，再生成窄范围回扩规格；至少覆盖装甲/手持槽、`InvWrapper` 包第三方 `IInventory`、`InventoryLargeChest`，每行关联源码、目标表或机器报告。
- T13 的第三方条目无源码时保持“无源码不可判定”；不得把安全收缩写成功能修复；作者不得承担最终独立复核。

### T15/T16

- T15 的“结构已落地”和“验证已通过”是两个状态，必须分别记录，不得用目录或编译存在替代全量构建/产物对比。
- T16 尚未开始收口；不得将 wrapper、依赖、发布配置或 MixinBooter 版本改动写入其他任务的验收结论。

## 统一交付要求

1. 任何状态更新必须同时说明产物状态、验收状态、独立复核和剩余风险。
2. 证据优先使用当前源码、测试输出、构建产物和可重放运行报告；第三方无源码统一标记缺口。
3. 生命周期任务、真实客户端、自动验收、字节码护栏和 `spotlessCheck` 分开记录；未执行不得写成通过。
4. 修改前读取目标文件并检查 `jj st`；修改后检查目标内容、`jj diff` 和租约范围。禁止用恢复、重置、清理或提交操作保护工作副本。
